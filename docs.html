كيفية البناء والتشغيل

المتطلبات

  • Java JDK 21 (OpenJDK) - sudo apt install openjdk-21-jdk
  • Apache Maven - sudo apt install maven

الطريقة 1: سطر الأوامر (الأسهل)

cd ~/Documents/multimedia-homework
mvn compile exec:java

أو ببساطة:

./run.sh

الطريقة 2: من VS Code

  1. افتح المجلد في VS Code
  2. افتح ملف Main.java
  3. اضغط F5 أو اذهب إلى Run > Start Debugging
  4. اختر "Run PixelLab" من القائمة
ملاحظة مهمة: إذا ظهر خطأ libpthread symbol lookup error، فهذا بسبب تعارض مكتبات snap مع Java. الحل: استخدم mvn compile exec:java أو شغّل من VS Code عبر F5 (ملف launch.json يعالج المشكلة تلقائياً).

البناء فقط (بدون تشغيل)

mvn compile

  1. 1. إدخال الصورة وعرضها: فتح من القائمة + السحب والإفلات (Drag & Drop)

  3. 3. عرض مركبات كل نظام لوني بشكل منفصل مع سلايدر للتعديل وخيار التعطيل
  4. 4. تمثيل الأنظمة اللونية في فضاءات ثنائية وثلاثية الأبعاد
  5. 5. التفاعل مع الفضاء اللوني: تدوير، تكبير، تحديد ألوان ومزامنة القيم + منتقي ألوان تفاعلي بنمط Chrome
  6. 6. تحديث لحظي عند أي تعديل (معالجة محسّنة بـ OpenCV والمعالجة المتوازية)

  8. 8. معلومات الصورة: الاسم، الصيغة، الأبعاد، العمق، الحجم

الخوارزميات المستخدمة

1. تحويل الأنظمة اللونية

جميع التحويلات مكتوبة يدوياً بالمعادلات الرياضية المعروفة في ColorConverter.java:

  • RGB ↔ HSV: حساب القيمة (max)، التشبع (diff/max)، صبغة اللون (زاوية 0°-360°)
  • RGB ↔ CMYK: K = 1 - max(R,G,B)/255، ثم C,M,Y نسبة إلى (1-K)
  • RGB ↔ YUV: مصفوفة التحويل القياسية مع إزاحة 128 لـ U,V
  • RGB ↔ YCbCr: معادلات ITU-R BT.601
  • RGB ↔ LAB: تحويل مرحلتين: RGB→XYZ (عبر gamma linearization + مصفوفة) ثم XYZ→LAB (مرجع D65)

عند تطبيق التعديلات على الصورة الكاملة، يستخدم ImageProcessor دوال OpenCV الأصلية (cvtColor) لتحويل الصورة بالكامل دفعة واحدة بدلاً من بكسل ببكسل، مما يوفر تسريعاً كبيراً بفضل كود C++ المحسّن بتعليمات SIMD.

2. تقليل عدد الألوان (K-Means++ عبر OpenCV)

يستخدم ImageProcessor.quantize() خوارزمية K-Means الأصلية من مكتبة OpenCV:

  1. تحويل بكسلات الصورة إلى مصفوفة Mat بأبعاد N×3 (نوع CV_32F)
  2. استدعاء kmeans() من OpenCV مع تهيئة K-Means++ (KMEANS_PP_CENTERS) لاختيار مراكز أولية أفضل
  3. 15 تكرار كحد أقصى مع شرط توقف عند الثبات (TermCriteria.EPS)
  4. استبدال كل بكسل بلون مركز مجموعته

K-Means++ يعطي نتائج أفضل وتقارب أسرع مقارنة بالتهيئة العشوائية، والتنفيذ الأصلي من OpenCV أسرع بكثير من تنفيذ Java البحت.

3. تعديل القنوات اللونية المحسّن

يستخدم ImageProcessor.applyChannelMods() استراتيجيتين حسب النظام اللوني:

  • للأنظمة المدعومة بـ OpenCV (HSV, YUV, YCbCr, LAB):
    تحويل الصورة بالكامل باستخدام cvtColor، ثم فصل القنوات بـ split، تعديل كل قناة باستخدام convertTo (مع تشبع تلقائي)، ثم دمج بـ merge وإعادة التحويل. يتضمن جداول تحويل بين مدى قيم التطبيق ومدى OpenCV لكل نظام لوني.
  • للأنظمة غير المدعومة (CMYK, RGB):
    معالجة متوازية باستخدام IntStream.parallel() مع مصفوفات بكسل مجمعة (getRGB/setRGB بالمصفوفة) للاستفادة من جميع أنوية المعالج.

4. الإسقاط ثلاثي الأبعاد

يستخدم إسقاط متعامد (Orthographic Projection) مع مصفوفات دوران حول المحورين X و Y: 

// Rotation around Y axis (yaw)
rx = x * cos(yaw) + z * sin(yaw)
rz = -x * sin(yaw) + z * cos(yaw)

// Rotation around X axis (pitch)
ry = y * cos(pitch) - rz * sin(pitch)

// Project to screen
screenX = centerX + rx * zoom
screenY = centerY - ry * zoom

5. منتقي الألوان التفاعلي (Color Picker)

منتقي ألوان بنمط Chrome يعمل في فضاء HSV:

  • مربع SV: المحور الأفقي = التشبع (Saturation: 0→1)، المحور العمودي = القيمة (Value: 1→0). يُعاد بناء المربع عند تغيير الصبغة.
  • شريط Hue: شريط عمودي يمثل الصبغة من 0° إلى 360°.
  • المزامنة: اختيار لون من أي مصدر (الصورة، الفضاء ثلاثي الأبعاد، المنتقي) يُحدّث جميع المكونات الأخرى تلقائياً.

كيفية استخدام التطبيق

  1. تحميل صورة: File > Open أو اسحب صورة إلى منطقة العرض
  2. تغيير النظام اللوني: اختر من القائمة المنسدلة "Color Space" في شريط الأدوات
  3. تعديل القنوات: انتقل إلى تبويب "القنوات"، حرّك السلايدر أو عطّل قناة
  4. الفضاء ثلاثي الأبعاد: تبويب "الفضاء اللوني" - اسحب للتدوير، عجلة الماوس للتكبير، انقر لاختيار لون
  5. منتقي الألوان: تبويب "منتقي الألوان" - اسحب المؤشر الدائري على مربع التشبع/القيمة، أو غيّر الصبغة من الشريط الجانبي
  6. اختيار لون من الصورة: انقر على أي بكسل في الصورة لعرض قيمه في جميع الأنظمة اللونية
  7. تقليل الألوان: غيّر قيمة "Colors" في شريط الأدوات
  8. معلومات الصورة: تبويب "معلومات"
  9. الإعادة: زر "Reset" في شريط الأدوات أو من القائمة
  10. الحفظ: زر "Save" أو File > Save (يدعم PNG, JPEG, BMP)
